# Community Project Case Studies

This directory contains engineering case studies of independently maintained open-source projects built with Model Studio.

These are more than lightweight usage examples: each project case documents the runtime architecture, deployment path, Model Studio integration, operational trade-offs, security boundaries, known limitations, and reproducibility status.

Inclusion does **not** make a project an official Alibaba Cloud product, nor does it imply ownership, endorsement, support SLA, or a confirmed commercial partnership.

## Status definitions

| Status | Meaning |
|---|---|
| `Incubating` | The integration and documentation are under review. Real-world stability, security, or maintenance continuity may still need validation. |
| `Verified` | The documented integration has passed reproducibility, security-boundary, and real external end-to-end checks. |
| `Featured` | A verified project with ongoing maintenance, public users, and repeatable production use cases. |

## Submit a project

[Open a Community Project Case proposal](https://github.com/modelstudioai/blog/issues/new?template=project-case.yml&labels=project-case) if your project:

- is maintained in an independent public repository with a clear license;
- uses Model Studio in the runtime or another essential project path;
- has reproducible setup documentation and real screenshots or demos;
- documents security boundaries, known limitations, and unverified claims;
- has a named maintainer who agrees to the case study and attribution.

# 社区项目案例

本目录收录由社区独立维护、基于阿里云百炼构建的完整开源项目工程案例。

它们区别于轻量使用案例：项目案例需要说明运行时架构、部署路径、阿里云百炼集成方式、工程取舍、安全边界、已知限制和可复现状态。

收录**不代表**项目成为阿里云官方产品，也不代表项目所有权转移、官方背书、支持 SLA 或商业合作已经确认。

## 状态定义

| 状态 | 含义 |
|---|---|
| `Incubating` | 接入和文档正在评审中，真实稳定性、安全性或持续维护情况仍可能需要验证。 |
| `Verified` | 已完成可复现性、安全边界和真实外部端到端验证。 |
| `Featured` | 已验证，且具备持续维护、公开用户和可重复生产实践。 |

## 提交社区项目

如果你的项目符合以下条件，可以[提交项目案例提案](https://github.com/modelstudioai/blog/issues/new?template=project-case.yml&labels=project-case)：

- 在独立公开仓库中维护，并有明确许可证；
- 阿里云百炼位于运行时或其他关键项目链路；
- 有可复现的部署说明，以及真实截图或演示；
- 清楚写出安全边界、已知限制和待验证事项；
- 有明确维护者，并同意案例收录与署名。
